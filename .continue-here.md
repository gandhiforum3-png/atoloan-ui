## Key Decisions Already Made

| Decision | Rationale |
|----------|-----------|
| Playwright for E2E | Native `page.route()` mocking, Vite-compatible |
| Vitest for unit tests | Zero-config for Vite, same ecosystem |
| Mocked backend for E2E | No FastAPI backend needed to run tests |
| Manual `npm run test` trigger | Developer decides when to run before `docker build` |
| `jsdom` pinned to `^26.1.0` | jsdom 27+ breaks Vitest (ESM error) — research finding |
