Create directory `tests/unit/` and file `tests/unit/setup.js` with the following content (D-03: cleanup + vi.unstubAllEnvs afterEach):

```javascript
import { expect, afterEach, vi } from 'vitest'
import { cleanup } from '@testing-library/react'
import matchers from '@testing-library/jest-dom/matchers'

expect.extend(matchers)

afterEach(() => {
  cleanup()
  vi.unstubAllEnvs()
})
```

This file:
- Extends Vitest `expect` with jest-dom matchers (e.g., `toBeInTheDocument`)
