```javascript
import { test, expect } from '@playwright/test'
import { registerAll } from './mocks/api.js'
```

**Test 1: E2E-09 Home page language switch**

1. `await page.goto('/')`
2. Assert EN state — nav link shows "Home": `await expect(page.getByRole('link', { name: /Home/ })).toBeVisible()`
3. Assert EN headline visible: `await expect(page.getByText('Auto Financing')).toBeVisible()`
4. Click language toggle (EN state has aria-label="Espanol"):
```javascript
await page.getByRole('button', { name: 'Espanol' }).click()
```
5. Assert ES state — nav link shows "Hogar": `await expect(page.getByRole('link', { name: /Hogar/ })).toBeVisible()`
6. Assert ES headline visible: `await expect(page.getByText('¡El auto nuevo comienza aquí!')).toBeVisible()`
7. Assert other nav links changed — "Prestamo" visible: `await expect(page.getByRole('link', { name: /Prestamo/ })).toBeVisible()`

**Test 2: E2E-10 Mid-wizard language switch**

1. `await registerAll(page)` — needed because wizard page makes API setup
2. `await page.goto('/loans')`
3. Assert EN step title: `await expect(page.getByRole('heading', { name: 'Select Loan Type' })).toBeVisible()`
4. Assert EN option button: `await expect(page.getByText('Auto Loans')).toBeVisible()`
5. Click language toggle:
```javascript
await page.getByRole('button', { name: 'Espanol' }).click()
```
6. Assert ES step title: `await expect(page.getByRole('heading', { name: 'Seleccione Tipo De Prestamo' })).toBeVisible()`
7. Assert ES option button: `await expect(page.getByText('Prestamo De Auto')).toBeVisible()`

**Important implementation notes:**
- The language toggle button uses `aria-label={labels.toggleAlt}` — in EN state it's `'Espanol'`, in ES state it's `'English'`.
- The toggle image at `/images/espanolbutton.png` will 404 in test env, but the `<button>` itself is still clickable via `getByRole('button', { name: 'Espanol' })` because `aria-label` is on the button element.
- For Test 1 (home page), no `registerAll` needed — no API calls on home page.
- For Test 2 (wizard), `registerAll` IS needed because the wizard page initializes and may trigger API setup.
- The ES headline has special characters: `'¡El auto nuevo comienza aquí!'` — use the exact string with accent marks.
