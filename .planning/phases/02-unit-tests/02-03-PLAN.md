From src/pages/loans/useLoanWizard.js:
```js
export default function useLoanWizard()
// Requires: LanguageProvider ancestor (calls useLanguage() internally)
// Returns object with:
//   stepIndex (number) — current step, starts at 0
//   step (object) — current step from getSteps array
//   answers (object) — { [stepId]: selectedValue }
//   contactInfo (object) — { firstName, lastName, email, address, city, state, zip, phone }
//   contactInfoErrors (string[]) — populated by handleContactInfoContinue on validation failure
//   emailValidationError (string) — set when email format is invalid
//   phoneValidationError (string) — set when phone is not 10 digits
//   handleSelect(value) — advances step; special branches for cosigner, monthly-income, time-at-job, down-payment, review
//   handleContactInfoContinue() — validates all 8 contact fields + email regex + phone digits; blocks advance on failure
//   handleContactInfoChange(field) => (event) => void — curried setter for contactInfo fields
//   setContactInfo, setOtherMonthlyIncome, setOtherDownPayment, setJobTitle, setTimeAtJobMonths, etc.
```

From src/pages/loans/loanSteps.js — Step indices (stable, 19 steps):
```
Index 0: 'loan-type' — initial step
Index 1: 'cosigner' — selecting 'by-myself' triggers skip to index 4
Index 2: 'cosigner-relative' — skipped by 'by-myself'
Index 3: 'same-address' — skipped by 'by-myself'
Index 4: 'employment' — target of cosigner skip
Index 16: 'contact-info' — where handleContactInfoContinue is relevant
```

Key handleSelect behavior:
- step.id === 'cosigner' && value === 'by-myself' => setStepIndex(steps.findIndex(s => s.id === 'employment')) which is index 4
- Default: if !isLastStep => setStepIndex(prev => prev + 1)

Key handleContactInfoContinue validation:
- Checks email regex: /^[^\s@]+@[^\s@]+\.[^\s@]+$/u — invalid => pushes 'please add valid email' to errors
- Checks phone digits: stripped non-digits must be length 10 — invalid => pushes 'please add valid phone number' to errors
- Checks 8 required fields: firstName, lastName, email, address, city, state, zip, phone — any missing => pushes 'Please fill in: {labels}.' to errors
- If errors.length > 0 || isLastStep => sets contactInfoErrors, returns early (does NOT advance)
